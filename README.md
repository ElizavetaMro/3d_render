# Документация проекта визуализации .wrl файлов

## Общее описание
Проект представляет собой инструмент для визуализации 3D-моделей из файлов формата .wrl (VRML). Программа способна обрабатывать сложные сцены с более чем 30 000 деталей, отображая их с использованием OpenGL.
## Структура проекта

### Основные модули:
1. **main.py** - точка входа в программу
2. **model.py** - класс для работы с 3D-моделями
3. **readfile.py** - парсер .wrl файлов
4. **render.py** - движок рендеринга с использованием OpenGL

## Подробное описание классов

### 1. Data (readfile.py)
**Назначение**: Парсинг .wrl файлов и подготовка данных для визуализации.

**Методы:**
- `__init__(self, file)` - конструктор, принимает путь к .wrl файлу
- `parse_wrl(self, file_path)` - парсит файл, извлекает вершины и индексы

**Возвращает:**
- Список моделей (экземпляров класса Model)
- Максимальную координату для нормализации

### 2. Model (model.py)
**Назначение**: Хранение данных о 3D-модели.

**Методы:**
- `__init__(self, vertices, indices, colors=None)` - конструктор модели
- `get_vertex_buffer(self)` - возвращает буфер вершин с цветами

**Особенности:**
- Автоматическая генерация цветов, если они не указаны
- Хранение данных в numpy массивах для эффективности

### 3. ModelRenderer (render.py)
**Назначение**: Визуализация 3D-моделей с использованием OpenGL.

**Основные методы:**
- `__init__()` - инициализация GLFW, создание окна, настройка шейдеров
- `load_model()` - загрузка модели в видеопамять
- `render()` - основной цикл рендеринга
- `cleanup()` - освобождение ресурсов

**Особенности:**
- Использование GLM для матричных преобразований
- Поддержка перспективной проекции
- Автоматическая анимация вращения моделей

## Пример использования
```python
from render import ModelRenderer
from readfile import Data

# Инициализация
renderer = ModelRenderer()
data = Data("path/to/file.wrl")

# Загрузка моделей
for model in data.model_list:
    renderer.load_model(model.get_vertex_buffer(), model.indices, data.max_coord/40)

# Запуск рендеринга
try:
    renderer.render()
finally:
    renderer.cleanup()
```

## Оптимизации
1. Использование numpy для эффективного хранения данных

4. Нормализация координат для корректного отображения
